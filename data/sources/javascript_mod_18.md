### 68. Maps [Data]
### Super Objects
A `Map` is like an object but keys can be *anything*, even other objects!

**Code Example / Starter**:
```javascript
const m = new Map();
m.set('a', 1);
console.log(m.get('a'));
```

**Solution Pattern**:
```javascript
const m = new Map(); m.set('a', 1); console.log(m.get('a'));
```

### 69. Sets [Data]
### Unique Arrays
A `Set` is a collection of unique values. Duplicates disappear automatically!

**Code Example / Starter**:
```javascript
const s = new Set([1, 1, 2]);
console.log(s.size);
```

**Solution Pattern**:
```javascript
const s = new Set([1, 1, 2]); console.log(s.size);
```
