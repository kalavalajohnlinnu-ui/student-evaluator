# [HTML & CSS] The CSS Box Model
**Description**: Control layout and spacing.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Box Model Basics [Box Model]
### Padding, Border, Margin
Every element is a box. Padding is inside, border is the edge, margin is outside.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { padding: 10px; margin: 10px; }
</style>
```

---

### 2. Box-sizing [Box Model]
### border-box
Make sizing easier by using box-sizing: border-box!

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
* { box-sizing: border-box; }
</style>
```

---

### 3. Display Property [Box Model]
### Block vs Inline
Block takes full width, inline only takes what it needs.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { display: inline-block; }
</style>
```

---

### 4. Overflow [Box Model]
### Overflow
What happens when content is too big? Use overflow: hidden or scroll.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { overflow: hidden; }
</style>
```
