### 1. Hello, Python! [Foundation]
### Welcome to Python! 🐍
Python is one of the world's most popular, human-readable programming languages. Created by Guido van Rossum, it is designed around simplicity and readability.

In Python, the **`print()`** function displays whatever you give it onto your terminal or screen.

```python
# This sends the message inside quotes to the output console
print("Hello, World!")
```

#### Rules for Strings:
- Text is called a **string** and must be wrapped in quotes (`"..."` or `'...'`).
- Python is case-sensitive: `print` works, but `Print` or `PRINT` will cause a `NameError`!

### 2. Comments & Clean Code [Readability]
### Speaking to Humans: Comments
Computers read code to execute it. Humans read code to understand it.

In Python, anything following a **`#`** symbol is a **comment**. The Python interpreter completely ignores comments when running your program.

```python
# This is a single-line comment. Python ignores this!
print("Python runs this line!")

"""
This is a multi-line string / comment.
Useful for long explanations or documentation.
"""
```

#### Why Comments Matter:
1. Explain **why** code was written a certain way.
2. Temporarily disable a line of code during debugging.

**Code Example / Starter**:
```python
# Fix this code:
# print("This line is commented out!")
# print("I am ready to master Python!")

```

**Solution Pattern**:
```python
print("I am ready to master Python!")
```
