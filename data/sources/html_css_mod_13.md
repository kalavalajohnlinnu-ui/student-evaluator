# [HTML & CSS] Positioning & Stacking
**Description**: Control elements precisely.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Positioning [Positioning]
### Position
Move things around with position: relative, absolute, or fixed.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { position: relative; top: 10px; }
</style>
```

---

### 2. Absolute & Fixed [Positioning]
### Absolute
Absolute positions relative to the nearest positioned ancestor.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { position: absolute; left: 0; }
</style>
```

---

### 3. Z-Index [Positioning]
### Stacking
Control what's on top with z-index.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { z-index: 10; }
</style>
```

---

### 4. Sticky [Positioning]
### Sticky headers
Make headers stick to the top when scrolling.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.header { position: sticky; top: 0; }
</style>
```
