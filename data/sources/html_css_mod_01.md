## Lessons & Concepts Covered:

### 1. Headings & Paragraphs [Structure]
### Welcome to HTML! 🎨
HTML stands for HyperText Markup Language. It gives every webpage its skeleton!

Elements are wrapped in opening and closing tags:
- `<h1>Big Title</h1>` for the main heading
- `<p>This is a paragraph of text.</p>` for text
- `<button>Click Me</button>` for clickable buttons!

**Code Example / Starter**:
```html_css
<!-- Write your HTML below -->
<h1>Hello World</h1>
<p>Welcome to the web!</p>

```

**Solution Pattern**:
```html_css
<h1>My Hero Quest</h1>
<p>I am learning to code!</p>
```

### 2. Buttons & Styling with CSS [Design]
### Adding Style with CSS
You can add colors, rounded corners, and glowing buttons using CSS:

```html
<button style="background-color: #38bdf8; color: #000; padding: 10px 20px; border-radius: 12px; font-weight: bold;">
  Launch Rocket 🚀
</button>
```

**Code Example / Starter**:
```html_css
<button style="background-color: blue; color: white;">
  Click
</button>

```

**Solution Pattern**:
```html_css
<button style="background-color: gold; color: black; font-weight: bold; padding: 8px 16px; border-radius: 8px;">
  Claim Reward ✨
</button>
```

### 3. The Hero Profile Card [Card Design]
### Creating Card Containers `<div>`
A `<div>` is like a cardboard box that holds text, buttons, and images together:

```html
<div style="background: #1e293b; color: white; padding: 20px; border-radius: 16px; text-align: center;">
  <h2>Hero Name</h2>
  <p>Level: 10</p>
</div>
```

**Code Example / Starter**:
```html_css
<div style="background: #1e293b; color: white; padding: 16px; border-radius: 12px;">
  <!-- Add your h2 and p here -->
</div>

```

**Solution Pattern**:
```html_css
<div style="background: #1e293b; color: white; padding: 16px; border-radius: 12px;">
  <h2>Cyber Knight</h2>
  <p>Power Level: 9000</p>
</div>
```
