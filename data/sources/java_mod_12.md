## Lessons & Concepts Covered:

### 1. Instanceof [Advanced]
### Instanceof\nLet's learn about Instanceof in Java! Think of it like a toy box where you organize your toys perfectly.

**Code Example / Starter**:
```java
public class Main {\n    public static void main(String[] args) {\n        // code\n    }\n}
```

**Solution Pattern**:
```java
public class Main {\n    public static void main(String[] args) {\n        System.out.println("Instanceof Complete!");\n    }\n}
```
