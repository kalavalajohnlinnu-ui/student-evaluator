### 1. Primitives [Types]
### Primitives\nLet's learn about Primitives in Java! Think of it like a toy box where you organize your toys perfectly.

**Code Example / Starter**:
```java
public class Main {\n    public static void main(String[] args) {\n        // code\n    }\n}
```

**Solution Pattern**:
