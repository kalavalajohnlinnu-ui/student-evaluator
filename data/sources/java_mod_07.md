## Lessons & Concepts Covered:

### 1. 1D Arrays [Data]
### 1D Arrays\nLet's learn about 1D Arrays in Java! Think of it like a toy box where you organize your toys perfectly.

**Code Example / Starter**:
```java
public class Main {\n    public static void main(String[] args) {\n        // code\n    }\n}
```

**Solution Pattern**:
```java
public class Main {\n    public static void main(String[] args) {\n        System.out.println("1D Arrays Complete!");\n    }\n}
```
