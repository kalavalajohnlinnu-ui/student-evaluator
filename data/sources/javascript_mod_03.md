### 13. Ternary Operator [Shortcuts]
### Ternary Shortcut
A shorter `if/else`: `condition ? trueValue : falseValue`.

**Code Example / Starter**:
```javascript
let score = 60;
console.log(score > 50 ? "Win" : "Lose");
```

**Solution Pattern**:
```javascript
let score = 60; console.log(score > 50 ? "Win" : "Lose");
```
