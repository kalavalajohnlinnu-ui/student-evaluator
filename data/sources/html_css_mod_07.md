# [HTML & CSS] Semantic HTML5
**Description**: Write meaningful HTML.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Header, Main, Footer [Semantics]
### Semantic HTML
Use tags that describe the content! header for the top, main for the middle, footer for the bottom.

**Code Example / Starter**:
```html_css
<!-- add main -->
```

**Solution Pattern**:
```html_css
<main>Content</main>
```

---

### 2. Section & Article [Semantics]
### Grouping Content
Use section for distinct parts, and article for self-contained content like a blog post.

**Code Example / Starter**:
```html_css
<!-- add article -->
```

**Solution Pattern**:
```html_css
<article>Blog</article>
```

---

### 3. Details & Dialog [Semantics]
### Interactive Semantics
Details creates a collapsible section, dialog creates a popup!

**Code Example / Starter**:
```html_css
<details>
</details>
```

**Solution Pattern**:
```html_css
<details>
<summary>Click Me</summary>
<p>Hidden text!</p>
</details>
```

---

### 4. Why Semantics Matter [Semantics]
### Screen Readers & SEO
Semantic HTML helps search engines and screen readers understand your page.

**Code Example / Starter**:
```html_css
<div>Links</div>
```

**Solution Pattern**:
```html_css
<nav>Links</nav>
```
