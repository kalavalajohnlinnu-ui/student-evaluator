## Lessons & Concepts Covered:

### 1. For Loop [Core]
### For Loop\nLet's learn about For Loop in Java! Think of it like a toy box where you organize your toys perfectly.

**Code Example / Starter**:
```java
public class Main {\n    public static void main(String[] args) {\n        // code\n    }\n}
```

**Solution Pattern**:
```java
public class Main {\n    public static void main(String[] args) {\n        System.out.println("For Loop Complete!");\n    }\n}
```
