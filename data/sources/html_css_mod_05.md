# [HTML & CSS] Images & Media
**Description**: Bring your pages to life.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Images [Media]
### img src/alt
Want to show a picture? Use the <img> tag! Remember to use 'alt' text for screen readers.

**Code Example / Starter**:
```html_css
<!-- add img -->
```

**Solution Pattern**:
```html_css
<img src="cat.jpg" alt="A cute cat" />
```

---

### 2. Figure [Media]
### figure and figcaption
Group an image and its caption together like a museum display!

**Code Example / Starter**:
```html_css
<figure>
</figure>
```

**Solution Pattern**:
```html_css
<figure>
<img src="art.jpg">
<figcaption>Art</figcaption>
</figure>
```

---

### 3. Audio & Video [Media]
### Playing Media
Embed music or movies right in your page using <audio> and <video> tags.

**Code Example / Starter**:
```html_css
<!-- add video -->
```

**Solution Pattern**:
```html_css
<video src="movie.mp4" controls></video>
```
