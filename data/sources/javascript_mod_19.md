### 72. Generators [Advanced]
### Pause and Play
A generator function `function*` can pause execution with `yield` and resume later.

**Code Example / Starter**:
```javascript
function* gen() { yield 1; }
console.log(gen().next().value);
```

**Solution Pattern**:
```javascript
function* gen() { yield 1; } console.log(gen().next().value);
```
