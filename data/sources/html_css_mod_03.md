## Lessons & Concepts Covered:

### 1. Headings & Paragraphs [Text]
### h1-h6 and p
Headings are like chapter titles in a book. h1 is the biggest, h6 is the smallest.

**Code Example / Starter**:
```html_css
<!-- add headings -->
```

**Solution Pattern**:
```html_css
<h1>Big</h1>
<h2>Smaller</h2>
```

### 3. Anchor Tags [Links]
### Links
Anchor tags <a> let you travel to other pages! Like magical portals.

**Code Example / Starter**:
```html_css
<!-- Add link -->
```

**Solution Pattern**:
```html_css
<a href="https://google.com">Google</a>
```

### 4. HTML Entities [Symbols]
### Special Characters
Need a copyright symbol? Use HTML entities like &copy;!

**Code Example / Starter**:
```html_css
<p>Copyright </p>
```

**Solution Pattern**:
```html_css
<p>Copyright &copy;</p>
```
