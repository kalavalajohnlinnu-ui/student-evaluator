# [HTML & CSS] Colors, Backgrounds & Typography
**Description**: Make it look beautiful.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Colors [Design]
### Hex & RGB
Use hex codes like #ff0000 or rgb(255,0,0) for colors.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
p { color: #ff0000; }
</style>
```

---

### 2. Backgrounds [Design]
### Gradients
Make cool backgrounds with linear-gradient!

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { background: linear-gradient(red, blue); }
</style>
```

### 3. Typography [Design]
### Fonts
Change the font-family, font-size, and font-weight.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
p { font-weight: bold; }
</style>
```

---

### 4. Google Fonts [Design]
### Web Fonts
Import custom fonts using @import or <link>.

**Code Example / Starter**:
```html_css
<!-- import font -->
```

**Solution Pattern**:
```html_css
<link href="https://fonts.googleapis.com/css?family=Roboto" rel="stylesheet">
<style>
p { font-family: 'Roboto'; }
</style>
```
