# [HTML & CSS] Forms & User Input
**Description**: Collect data from users.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Forms [Forms]
### form/input/label
Forms let users send data! Like filling out a survey.

**Code Example / Starter**:
```html_css
<form>
</form>
```

**Solution Pattern**:
```html_css
<form>
<input type="text">
</form>
```

### 2. Input Types [Forms]
### Types of Inputs
Inputs can be passwords, dates, or checkboxes!

**Code Example / Starter**:
```html_css
<!-- add password input -->
```

**Solution Pattern**:
```html_css

```

### 3. Textarea & Select [Forms]
### Long Text & Dropdowns
Need more space? Use textarea. Need choices? Use select and option.

**Code Example / Starter**:
```html_css
<!-- add textarea -->
```

**Solution Pattern**:
```html_css
<textarea></textarea>
```

---

### 4. Form Validation [Forms]
### Required Fields
Make sure users don't skip questions by adding the 'required' attribute.

**Code Example / Starter**:
```html_css
<input type="text">
```

**Solution Pattern**:
```html_css
<input type="text" required>
```

---

### 5. Buttons [Forms]
### Button Types
Buttons can submit forms or just be clickable.

**Code Example / Starter**:
```html_css

```

**Solution Pattern**:
```html_css

```
