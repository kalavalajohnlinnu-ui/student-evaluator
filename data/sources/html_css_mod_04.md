# [HTML & CSS] Lists & Tables
**Description**: Organize data effectively.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Lists [Lists]
### ul, ol, li
Need a shopping list? Use <ul> for bullets and <ol> for numbers. <li> is for each item.

**Code Example / Starter**:
```html_css
<ul>
</ul>
```

**Solution Pattern**:
```html_css
<ul>
<li>Apples</li>
<li>Bananas</li>
</ul>
```

---

### 2. Data Tables [Tables]
### tables
Tables are like Excel sheets. thead is the header, tbody is the body, tr is a row, th is a header cell, td is a data cell.

**Code Example / Starter**:
```html_css
<table>
</table>
```

**Solution Pattern**:
```html_css
<table><tr><td>Data</td></tr></table>
```

---

### 3. Table Styling [Tables]
### Table Borders
Tables look invisible by default. Let's add CSS to show borders!

**Code Example / Starter**:
```html_css
<table></table>
```

**Solution Pattern**:
```html_css
<table style="border: 1px solid black;"></table>
```
