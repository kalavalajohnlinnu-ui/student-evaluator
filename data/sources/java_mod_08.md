### 1. Defining Methods [Core]
### Defining Methods\nLet's learn about Defining Methods in Java! Think of it like a toy box where you organize your toys perfectly.

**Code Example / Starter**:
```java
public class Main {\n    public static void main(String[] args) {\n        // code\n    }\n}
```

**Solution Pattern**:
