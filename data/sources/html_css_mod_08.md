# [HTML & CSS] CSS Selectors & Specificity
**Description**: Target elements precisely.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Selectors [CSS]
### Selectors
Use CSS to target elements, classes (.), or IDs (#).

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.box { color: red; }
</style>
```

---

### 2. Combinators [CSS]
### Combinators
Target elements inside other elements using space, >, +, or ~.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
div p { color: blue; }
</style>
```

---

### 3. Pseudo-classes [CSS]
### Pseudo-classes
Target state like :hover when the mouse is over an element.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
a:hover { color: red; }
</style>
```

---

### 4. Pseudo-elements [CSS]
### Pseudo-elements
Target parts of an element like ::before or ::first-line.

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
p::first-letter { font-size: 2em; }
</style>
```
