# [HTML & CSS] HTML Document Structure
**Description**: Learn the foundation of every HTML page.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. DOCTYPE [Core]
### DOCTYPE
Every HTML page needs a DOCTYPE. Think of it like a nametag telling the browser what language we are speaking!

**Code Example / Starter**:
```html_css
<!-- Add doctype -->
<html></html>
```

**Solution Pattern**:
```html_css
<!DOCTYPE html>
<html></html>
```

---

### 2. html/head/body [Core]
### The HTML Skeleton
An HTML file is like a human body. The <head> is the brain (hidden thoughts), and the <body> is what you can see!

**Code Example / Starter**:
```html_css
<html>
<!-- add head and body -->
</html>
```

**Solution Pattern**:
```html_css
<html>
<head></head>
<body></body>
</html>
```

---

### 3. title/meta, link/script [Core]
### Title and Links
The <title> is what shows up on the browser tab! We can also link other files like CSS or JavaScript.

**Code Example / Starter**:
```html_css
<head>
  <!-- Add title here -->
</head>
```

**Solution Pattern**:
```html_css
<head>
  <title>My Webpage</title>
</head>
```
