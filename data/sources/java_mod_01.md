## Lessons & Concepts Covered:

### 1. Hello, Java! [Core]
### Welcome to Java! ☕
Java is like a factory. Every piece of code belongs to a blueprint called a `class`.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello!");
    }
}
```

**Code Example / Starter**:
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

```

**Solution Pattern**:
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Welcome to Java Hero!");
    }
}
```

### 2. Variables & Arithmetic [Core]
### Data Types in Java
Think of variables like labeled boxes. A box labeled `int` only holds whole numbers!

```java
int a = 20;
int b = 30;
System.out.println(a + b);
```

**Code Example / Starter**:
```java
public class Main {
    public static void main(String[] args) {
        int attack = 15;
        int bonus = 10;
        System.out.println(0);
    }
}

```

**Solution Pattern**:
```java
public class Main {
    public static void main(String[] args) {
        int attack = 15;
        int bonus = 10;
        System.out.println(attack + bonus);
    }
}
```
