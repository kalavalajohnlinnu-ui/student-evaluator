# [HTML & CSS] CSS Flexbox Layout
**Description**: Master flexible layouts.

**Platform Source**: https://kalavalajohnlinnu-ui.github.io/codehero-1717/

**Language Realm**: HTML & CSS

## Lessons & Concepts Covered:

### 1. Display Flex [Flexbox]
### Flexbox
Flexbox makes laying out items in a row or column super easy!

**Code Example / Starter**:
```html_css
<style>
</style>
```

**Solution Pattern**:
```html_css
<style>
.container { display: flex; }
</style>
```
